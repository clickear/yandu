# 003 · 服务端与协作后续计划

依据：[spec 003 草案](../specs/003-backend-collaboration.md)。尚未实施。

## 阶段 A：确认产品与接口

- [ ] 确认部署、数据库、认证与组织模型。
- [ ] 明确角色、审核状态机、版本冲突、资源格式与发布规则。
- [ ] 定义项目 / 语言 / 文案 / 译文 / 审核事件接口和错误响应。
- [ ] 设计本地工作空间的完整导出与迁移格式。

## 阶段 B：持久化与迁移

- [ ] 建立可迁移数据库、服务端验证和项目级隔离。
- [ ] 将 UI 数据访问封装为适配器，保留原型作为本地模式。
- [ ] 支持幂等导入、版本检查、完整备份与恢复。
- [ ] 实施源文案编辑、条目 / 项目重命名、归档与可恢复删除。

## 阶段 C：协作与交付

- [ ] 实现登录、邀请、授权、审核日志与并发冲突反馈。
- [ ] 根据正式规格增加术语表、机器翻译和资源包发布。
- [ ] 执行 API / 数据库 / 权限 / 并发 / 恢复验证。
- [ ] 明确数据存放、部署维护与回滚方案后再准备生产发布。

阶段 B 依赖阶段 A；阶段 C 依赖阶段 B。当前浏览器原型不需要任何服务端凭据；不要提前添加虚构的 API Key 或模拟后端成功状态。
