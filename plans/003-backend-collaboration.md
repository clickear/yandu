# 003 · 服务端与协作后续计划

依据：[spec 003](../specs/003-backend-collaboration.md) 和[DDD 技术设计](../docs/ddd-technical-design.md)。DDD 技术设计已形成；后端正在实现，产品决策与阶段验收仍未完成。

## 当前实现进度

- 已建立 `backend/` Spring Boot / MyBatis-Plus 模块化单体工程与 MySQL 迁移基线。
- Workspace 项目创建、默认命名空间、目标语言配置和 Catalog 源词条切片已建立；Catalog 支持创建、源文变更、检索分页、修订历史和归档。实体 ID 使用 `BIGINT` 雪花算法，JSON 边界按十进制字符串处理。
- 已接入通用 OIDC JWT、issuer/audience 校验、OIDC subject 到内部雪花 ID 映射、项目成员角色授权和 `/api/v1` 项目/Catalog API。IdP 与 audience 需由部署环境提供；租户模式和 Outbox 未实现。
- Translation 已有版本化保存、送审/审核、源文更新后自动标记待复核与权限检查；基础质量检查识别必填译文和 `{name}` 命名占位符差异，并在送审时阻断。已增加项目术语管理、源文术语建议和当前源文完全匹配的已审核译文建议（各上限 10 条）；模糊匹配、其他占位符格式、可配置规则和质量报告历史尚未实现。
- Release 支持 JSON 与 Java Properties 不可变快照，发布前检查译文已审核、基于当前源版本且命名占位符一致；保存来源清单（词条、源版本、译文版本）及 SHA-256，提供历史元数据和原格式下载。Properties 使用稳定排序及 ASCII `\\uXXXX` 转义，可由 Java `Properties.load(InputStream)` 读取。回滚会复制旧格式快照并创建新版本，记录 `rollback_of_release_id`。对象存储尚未实现。
- Import 已支持严格扁平字符串 JSON 解析、差异预览、项目内幂等键、预览 SHA-256 确认、持久化异步任务、状态查询、失败重试和 30 分钟失联任务回收；apply 时重检项目配置及词条/译文版本。此阶段限 5 MiB / 10,000 项，目标语言导入要求对应源 key 已存在。前端 API 模式已接入预览确认与任务提交。
- 前端已提供本地原型/API 两种明确模式；服务端模式使用 OIDC Authorization Code + PKCE，无示例数据；支持项目/语言/成员/词条管理、服务端分页搜索与状态筛选、译文保存送审/审核、网络失败后恢复编辑草稿、源文案修改/历史/归档、JSON 导入预览与状态追踪、发布下载。具体 IdP、API URL 和 audience 由部署环境配置。
- AuditLog 已在业务事务中记录项目/语言/成员、词条、译文审核、导入和发布/回滚操作；敏感源文和译文正文不写入审计元数据，并提供项目成员分页读取接口。
- Spring Boot Actuator 已仅暴露健康端点；`/livez` 只检查进程存活，`/readyz` 将 MySQL 连通性纳入就绪检查。探针匿名可访问，健康组件名和详情不对外返回；数据库断连时的真实运行时状态仍待 MySQL 8.0 环境验证。
- 用户要求大模块完成后集中验证；运维健康探针接入后，JDK 21 下后端 36 项测试通过（含 Spring Modulith 边界检查）；前端 25 项测试和生产构建通过。已添加 MySQL 8.0 Compose 配置；当前环境无 Docker，无法启动实例验证迁移。完整 UI→OIDC→API→MySQL 业务链仍未实测。

## 阶段 A：产品与接口决策

- [x] 用户确认 MySQL 8.0、MyBatis-Plus、数字 ID、本期不实现租户模式与 Outbox；Java/Spring 作为当前 DDD 工程基线。
- [ ] 配置 OIDC 身份提供方及 audience；部署服务和凭据由部署环境提供。
- [ ] 如需实际切换数据库，指定第二目标方言并运行同一持久化契约；在指定前不宣称已兼容任意数据库。

- [ ] 冻结资源格式与占位符规则、质量门禁、发布/回滚流程和数据保留策略。
