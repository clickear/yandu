# 003 · 服务端与协作后续计划

依据：[spec 003](../specs/003-backend-collaboration.md) 和[DDD 技术设计](../docs/ddd-technical-design.md)。DDD 技术设计已形成；后端正在实现，产品决策与阶段验收仍未完成。

## 当前实现进度

- 已建立 `backend/` Spring Boot / MyBatis-Plus 模块化单体工程与 MySQL 迁移基线。
- Workspace 项目创建、默认命名空间、目标语言配置和 Catalog 源词条切片已建立；Catalog 支持创建、源文变更、检索分页、修订历史和归档。实体 ID 使用 `BIGINT` 雪花算法，JSON 边界按十进制字符串处理。
- 已接入通用 OIDC JWT、issuer/audience 校验、OIDC subject 到内部雪花 ID 映射、项目成员角色授权和 `/api/v1` 项目/Catalog API。IdP 与 audience 需由部署环境提供；租户模式和 Outbox 未实现。
- Translation 已有版本化保存、送审/审核、源文更新后自动标记待复核与权限检查；基础质量检查识别必填译文和 `{name}` 命名占位符差异，并在送审时阻断。已增加项目术语管理、源文术语建议和当前源文完全匹配的已审核译文建议（各上限 10 条）；模糊匹配、其他占位符格式、可配置规则和质量报告历史尚未实现。
- Release 支持 JSON 与 Java Properties 不可变快照，发布前检查译文已审核、基于当前源版本且命名占位符一致；保存来源清单（词条、源版本、译文版本）及 SHA-256，提供历史元数据和原格式下载。Properties 使用稳定排序及 ASCII `\\uXXXX` 转义，可由 Java `Properties.load(InputStream)` 读取。回滚会复制旧格式快照并创建新版本，记录 `rollback_of_release_id`。对象存储尚未实现。
- Import 已支持严格扁平字符串 JSON 解析、差异预览、项目内幂等键、预览 SHA-256 确认、持久化异步任务、状态查询、失败重试和 30 分钟失联任务回收；apply 时重检项目配置及词条/译文版本。此阶段限 5 MiB / 10,000 项，目标语言导入要求对应源 key 已存在。前端 API 模式已接入预览确认与任务提交。
- 前端已提供本地原型/API 两种明确模式；服务端模式使用 OIDC Authorization Code + PKCE，无示例数据；支持项目/语言/成员/词条管理、服务端分页搜索与状态筛选、译文保存送审/审核、网络失败后恢复编辑草稿、源文案修改/历史/归档、JSON 导入预览与状态追踪、发布下载，以及本地项目迁移预览和异步进度查询。具体 IdP、API URL 和 audience 由部署环境配置。
- B12 本地迁移切片已实现：严格重复字段校验、UTF-8 JSON v1 包校验/规范化、项目名称预览冲突、重新生成服务端 ID、译文重置为草稿、持久化分块任务与 ID 映射、同包幂等和失败重试。后端全套 37 项测试及 Spring Modulith 边界检查通过；前端 Node 22 生产构建通过。MySQL 8.0 迁移脚本和 UI→API 集成仍需环境验证。
- AuditLog 已在业务事务中记录项目/语言/成员、词条、译文审核、导入和发布/回滚操作；敏感源文和译文正文不写入审计元数据，并提供项目成员分页读取接口。
- Spring Boot Actuator 已仅暴露健康端点；`/livez` 只检查进程存活，`/readyz` 将 MySQL 连通性纳入就绪检查。探针匿名可访问，健康组件名和详情不对外返回；数据库断连时的真实运行时状态仍待 MySQL 8.0 环境验证。
- Catalog 端口已将源词条与 `GlossaryTerms` 分开，分页结果与总数按同一查询返回；Translation 工作台将列表和统计作为一个查询结果，保留单个 MyBatis 适配器与现有测试文件。
- Workspace 生命周期与成员权限切片已完成：项目说明和默认目标语言、Owner/Admin 成员管理、角色变更/移除/离开、Owner 转让、项目及目标语言归档/恢复；归档项目仍显示并允许成员读取历史。规则放入 `Project` 聚合，由应用服务协调仓储与审计。JDK 21 下后端 37 项测试（含模块边界）和 Node 22 前端生产构建通过；V6 迁移仍待真实 MySQL 8.0 验证。
- 机器翻译主流程已实现 LibreTranslate-compatible provider port/HTTP adapter、MySQL 持久任务与词条快照、幂等创建、最多四个并发 worker、进度/分页结果、失败项重试与失联回收；译文写入与任务项完成在同一事务中，回填时锁定源词条并校验源修订、译文版本和译文空值，结果保存为草稿。前端支持发起、查看和重试；provider 未配置时拒绝创建。JDK 21 下后端全套 40 项测试通过（包括 provider 本地 HTTP 协议检查和模块边界），Node 22 前端生产构建通过。当前环境没有 Docker/MySQL 8.0 服务，V7 数据库执行与真实 provider 调用仍待环境实测。
- 命名空间管理切片已补齐：Owner/Admin 可创建、重命名、查询、归档与恢复；领域对象约束名称及生命周期，归档仅允许无活动词条的命名空间。创建词条对活动命名空间加事务行锁，与归档互斥；前端可切换命名空间，按当前命名空间检索、添加文案及预览导入。使用既有 `namespaces` 表，无需新增迁移。JDK 21 后端全套测试与 Node 22 前端生产构建通过；MySQL 8.0 并发行为仍待真实实例验证。
- 词条整理切片已补齐：Owner/Admin 可改键和跨命名空间移动，要求当前目录版本；领域对象递增目录版本但不递增源修订，数据库唯一约束保证项目内键唯一，前端提供整理操作和冲突提示。MySQL V8 收紧 `catalog_entries` 唯一索引；导入预览按项目内 key 匹配，因此可在其他 namespace 导入目标译文而不误建重复词条。升级前需检查项目内重复 key 并人工处理。MySQL 8.0 上 V8 与并发路径仍待实测。
- 发布查看切片已补齐：发布/回滚 API 仅回传版本元数据；工作台可按语言查看快照版本、条目数、校验和、操作者和时间，下载历史版本或将旧快照作为新版本回滚。详情/下载仍逐次校验 SHA-256，发布校验失败会显示门禁原因。JDK 21 后端测试与 Node 22 前端构建通过；真实 MySQL 8.0 发布闭环尚待环境验收。
- 审核工作流的退回路径已接通：Reviewer/Owner/Admin 可填写原因退回当前送审译文；译者重新打开已退回译文时可查看最新审核意见和时间。前端区分草稿、审核中、已退回、需复核和已审核，并支持对应服务端筛选。领域规则与审核记录复用既有 `REQUEST_CHANGES` 决策；JDK 21 后端全套测试及 Node 22 前端构建通过。MySQL 8.0 审计持久化及真实双用户链路仍待实测。
- 用户要求大模块完成后集中验证；Catalog 只读查询与行锁读取分离后，JDK 21 下后端 37 项测试通过（含 Spring Modulith 边界检查）；前端 25 项测试和生产构建通过。已添加 MySQL 8.0 Compose 配置；当前环境无 Docker，无法启动实例验证迁移。完整 UI→OIDC→API→MySQL 业务链仍未实测。
