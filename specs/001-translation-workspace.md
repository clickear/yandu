# 001 · 翻译工作台原型

状态：本轮确认范围。对应 [实施计划](../plans/001-translation-workspace.md)。

## 目标与边界

让一个人无需后端即可验证「项目 → 语言 → 文案 → 翻译 → 审核 → 导出」流程。React + TypeScript + Vite；浏览器 `localStorage` 存储版本化工作空间。启动不要求网络服务或凭据，字体和图标可离线加载。

本次不实现账号、权限、服务端持久化、协同编辑、机器翻译、ICU 校验、删除或重命名。它不是生产部署完成声明。

## 行为与验收

| ID  | 行为           | 可验证结果                                                                        |
| --- | -------------- | --------------------------------------------------------------------------------- |
| T01 | 创建和切换项目 | 名称不能为空且最多 80 字；项目数据相互隔离                                        |
| T02 | 添加目标语言   | 支持 zh-CN、en-US、ja-JP、fr-FR、de-DE、es-ES、zh-TW；不能重复或等于源语言        |
| T03 | 添加文案       | 项目内键唯一、去除首尾空白、1–200 字符；源文案非空                                |
| T04 | 保存译文和审核 | 译文可留空；非空才可审核；编辑文本后自动取消审核                                  |
| T05 | 搜索和状态过滤 | 搜索当前目标语言的键名、源文案及译文；切换语言清除搜索与筛选                      |
| T06 | 语言进度       | 已翻译数按非空译文统计，审核数独立；空项目进度为 0                                |
| T07 | 导入 JSON      | 仅扁平对象和字符串值，最大 1 MB；最多 10,000 个键；非法内容整份拒绝，已有数据不变 |
| T08 | 合并与审核失效 | 同键只更新所选语言；源文案变化使其所有译文回到待审核；内容不变保留审核状态        |
| T09 | 导出 JSON      | 当前目标语言的完整扁平映射；缺失译文为空字符串；Unicode 不丢失                    |
| T10 | 本地保存与恢复 | 刷新保留所有项目与审核状态；未知版本、损坏数据不自动覆盖；存储失败给出导出提示    |
| T11 | 可操作界面     | 弹窗有标题、焦点约束、Escape 关闭；译文未保存时确认放弃；手机仅表格区域横向滚动   |
| T12 | 示例           | 首次提供标识清晰的中英日示例，供立即操作；真实数据仅存于当前浏览器                |

## 数据模型

```text
Workspace { version: 1, projects: Project[] }
Project { id, name, description, sourceLanguage, targetLanguages[], entries[] }
Entry { id, key, source, translations: Record<locale, { value, status }> }
status = draft | reviewed
```

「未翻译」由空白译文推导，不单独持久化。审核针对一个键的一个目标语言。JSON 导入导出不携带内部 ID 或审核状态；不应作为完整工作空间恢复文件。导入目标语言的新键允许源文案暂空，用户可通过源语言 JSON 补充。

保留路径字段 `__proto__`、`prototype`、`constructor` 不可作为键的点分段。内容按文本显示，不解释 HTML。不承诺多标签页并发写入安全；目前使用最后保存者覆盖行为。

## 验证

数据与格式规则由 `src/model.test.ts` 验证，真实交互、刷新持久化、文件导入导出、损坏存储保护和手机布局由 `tests/e2e/workspace.spec.ts` 验证；类型检查与生产构建必须通过。
