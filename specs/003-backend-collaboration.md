# 003 · 服务端与团队协作（未来草案）

状态：未实施，需正式产品规格确认。对应 [后续计划](../plans/003-backend-collaboration.md)。

本轮用户同意将后端和多人协作放在后续计划。以下是接入点与待决策问题，不能视为已获确认的技术方案。

## 候选能力

1. 持久化项目、键、语言、译文、审核事件，提供原型数据迁移与完整备份恢复。
2. 登录与组织；项目拥有者、译者、审核者角色，以及邀请和退出流程。
3. 审核事件和文案版本；乐观锁或版本号防止并发覆盖；明确撤回策略。
4. 大文件导入预览、冲突报告、后台任务、导出版本与发布资源包。
5. 可选机器翻译适配器、额度限制和术语表；凭据只在服务端安全配置。
6. 项目 / 条目 / 语言的重命名、归档、删除、恢复；危险操作需可审计。

## 决策前置

- 数据库、后端语言、部署目标、登录方式、租户隔离策略。
- 协作角色、审核规则、同一键并发冲突的处理方式。
- 资源格式（嵌套 JSON / ICU / YAML / PO 等）与占位符保护。
- 本地工作空间迁移与跨标签页、跨设备一致性。

## 未来验收

必须有真实 API / 数据库集成测试、权限隔离测试、并发更新冲突测试、迁移回滚与备份恢复验证。在这些能力落地前，界面仍应明确标注本地原型，不展示模拟登录或协作成功状态。
