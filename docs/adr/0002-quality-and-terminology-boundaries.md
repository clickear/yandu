# 质量与语言知识独立于目录管理

Quality 拥有质量规则和检查结果，Terminology/Memory 拥有术语与翻译记忆；Catalog 只拥有命名空间、源词条和源文本历史，Translation 拥有译文与审核状态。质量检查由送审和发布共同调用，避免重复规则；错误会阻止送审和发布，但允许保存草稿；发布时使用的检查结果随发布版本留存，不单独保存临时检查历史。首期只识别 `{name}` 命名占位符及其重复次数，`{{`/`}}` 表示字面花括号；不支持的花括号格式作为错误处理。术语和记忆按项目隔离：同一源/目标语言对每个源术语只有一个首选译法，术语按大小写不敏感子串匹配并优先显示较长词条；记忆只用同项目、当前源文版本的已审核完全匹配译文，多个候选均展示且不自动覆盖。模块边界按业务所有权划分，但简单持久化可继续复用 MyBatis 适配器，不因边界而制造多层转发类。
