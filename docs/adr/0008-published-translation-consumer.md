# 已发布翻译的消费端同步

发布消费端使用独立的 Spring Boot Starter，按配置的项目、目标语言和格式同步最新已发布版本。平台提供公开只读元数据与快照接口；接口只暴露已发布内容，不提供草稿、审核数据或项目协作操作，本期不要求消费端身份认证。工作台管理 API 继续使用 OIDC 和项目角色授权。

快照是不可变发布内容。Starter 先读取版本及 SHA-256 元数据，再下载对应的最新内容；只有内容校验和解析成功后才用一次原子替换更新内存目录。同步失败时保留上一个有效目录，并在下一轮继续重试。消费应用通过 `TranslationCatalog` 按键读取当前快照，不需要依赖平台数据库。

同步传输方式以配置选择：普通 HTTP 轮询作为兼容性兜底，HTTP 长轮询减少无变更时的请求，SSE 用于服务端单向推送。三种传输复用相同的不可变快照、SHA-256 校验和本地原子替换契约。首期轮询间隔默认 60 秒，长轮询等待时间有上限，断线后自动重连。

WebSocket 暂不实现，因为当前消费协议只有服务端向客户端发布快照；Netty 是可选的网络运行时实现，不作为同步协议配置项。若后续消费者需要双向控制消息，再评估 WebSocket。远程缓存持久化和 webhook 暂不实现；公开接口只支持 JSON Flat v1 与 Java Properties v1。普通轮询已实现，HTTP 长轮询与 SSE 仍待实现和验证。
